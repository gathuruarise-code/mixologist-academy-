# Mixology Academy – Website and Android app starter

This is a responsive, self-contained mixology study website with:
- Bartending and mixology fundamentals
- Bar terms, tools and glassware
- Beverage classifications
- Tequila, whiskey, gin, vodka, wine and brandy notes
- Cocktail recipes, methods, glassware and garnishes
- Searchable notes and an interactive quiz
- Print support and Progressive Web App (PWA) install support

## Preview on a laptop
Open `index.html` in a modern browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository, e.g. `mixology-academy`.
2. Upload **all files** from this folder (keep their filenames).
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the published website link shown in Pages.

## Install as an Android app
1. Publish it over HTTPS using GitHub Pages (or another HTTPS host).
2. Open the published website in Chrome on Android.
3. Tap Chrome's three-dot menu.
4. Choose **Install app** or **Add to Home screen** (wording varies).
5. Confirm. It will open in an app-like standalone window.

The website includes a PWA manifest and service worker. For a Play Store release, you will need a separate Android packaging/signing and Play Console process; this starter does not automatically publish to Google Play.

## Important
The recipes are educational examples. Follow your venue's approved measures, local law, age restrictions, food-safety rules and responsible alcohol-service policies. Check local product standards for exact spirit definitions and ABV.
